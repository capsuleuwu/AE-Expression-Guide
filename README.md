# AE 表達式圖鑑

After Effects 表達式的互動參考。依類別整理常用表達式，每個範例都能即時預覽、用滑桿調整參數，也能直接修改程式碼看結果。

## 功能

- **分類清楚**：時間、隨機與抖動、循環、插值與映射、數學與週期運動、關鍵影格與物理、圖層引用與 index、表達式控制效果、文字、顏色、形狀路徑、條件與標記、JavaScript 基礎語法，以及可自由撰寫的實驗室。
- **即時預覽**：1920×1080、30 fps 的合成畫面，含時間軸（關鍵影格、標記）與數值圖表。
- **參數調整**：在數值變數後面加上 `// @標籤 最小~最大 間距`，就會自動產生滑桿，例如：

  ```javascript
  amp = 50; // @幅度 0~200 1
  ```

- **自由編輯**：語法高亮，錯誤會像 AE 一樣標出行號。
- **效果控制**：模擬滑桿、核取方塊、顏色、點、角度控制。
- **收藏**：把修改過的版本存到「我的表達式」。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可，不需要安裝任何東西（需要網路以載入語法解析器 acorn 與字型）。

收藏與修改預設存在瀏覽器的 localStorage。在 claude.ai 上開啟時，會自動透過 Claude 帳號同步到其他裝置。

## 專案結構

```
index.html        組合後的完整網頁（可直接開啟）
build.py          把 src/ 組合成 index.html
src/shell.html    版面與樣式
src/engine.js     AE 表達式直譯引擎（陣列運算、wiggle、loopOut、valueAtTime 等）
src/examples.js   所有範例與分類
src/ui.js         介面：預覽、時間軸、圖表、編輯器、參數
```

修改 `src/` 後執行：

```bash
python3 build.py
```

## 說明

此頁以瀏覽器模擬 AE 的 JavaScript 表達式引擎，結果與 AE 相近，但 `wiggle`、`random`、`noise` 的實際數值會與 AE 不同。
